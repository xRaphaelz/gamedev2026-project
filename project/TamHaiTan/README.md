# ตำให้ทัน! (Godot 4.7.2)

เกมทำอาหาร 3D ร้านส้มตำริมทาง แนว Overcooked เล่นคนเดียว

## เปิดโปรเจกต์
Godot 4.7.2 → Import → เลือก `project.godot` → กด F5 (เริ่มที่เมนูหลัก)

## ลำดับเกม
เมนูหลัก → คัตซีนก่อนบท → บทสนทนา (บท 1) → เล่นด่าน → สรุปรีวิว → บทถัดไป ... → ตอนจบ 3 แบบตามรีวิวเฉลี่ย
(≥ 4.0 ดาว = ตอนจบดี, 2.5–3.9 = กลาง, < 2.5 = แย่ — ปรับได้ที่ `ENDING_GOOD/ENDING_MID` ใน game_state.gd)
(ครั้งแรกที่เปิดอาจมี error เรื่องฟอนต์ใน Output ระหว่าง import ไม่ต้องสนใจ)

## ปุ่ม
เนื้อเรื่อง: Enter/Space/คลิก ไปต่อ • Esc ข้าม
WASD เดิน • E หยิบ/วาง/ใช้สถานี • Space ตำ/หั่น (กดรัว) • Esc หยุด • Enter เริ่ม/ไปต่อ • R เล่นใหม่

## วงจรเล่น
กล่องวัตถุดิบ → (เขียง: หั่นมะละกอ ตั้งแต่บท 2) → ครก (ใส่ของแล้วกด Space ตำ) → ถือจานเปล่ากด E ที่ครก → เสิร์ฟ
ส่วนผสมไม่ตรงสูตร = "ส้มตำมั่ว" โดนหักคะแนน / ออเดอร์หมดเวลา = ลูกค้ากลับ หักคะแนน

## โมเดลและภาพ
โมเดลทั้งหมดเป็นงานที่ทำขึ้นเองด้วยสคริปต์ Blender ใน `tools/blender/` (อาหาร สถานี ฉากร้าน ตึกแถว ตัวละคร 5 ตัว ไอคอนเมนู และรูปหน้าตัวละคร)
แก้สี/รูปทรงแล้วสร้างใหม่ได้ด้วย `python3 tools/blender/build.py all` (ต้องติดตั้ง `pip install bpy`) หรือเปิดไฟล์ .glb ใน Blender แก้เองก็ได้
แต่ละด่านมีช่วงเวลาต่างกัน (เช้า / กลางวัน / เย็น) ตั้งได้ที่ `time_of_day` ในไฟล์ด่าน

## เสียง
เสียงประกอบ 20 แบบและเพลง 5 เพลง (ระนาด แคน ฉิ่ง กลอง) สังเคราะห์ด้วย `tools/audio/make_audio.py` ไม่ได้ใช้ไฟล์จากที่อื่น
แก้ทำนอง/เสียงแล้วรันใหม่ได้ (ต้องมี numpy, scipy, ffmpeg)

## คัตซีน / วิดีโอ
คัตซีนเล่นในเกมแบบ real-time และ export เป็นวิดีโอได้ด้วย Movie Maker ของ Godot:
`godot --path . --write-movie level_1.avi --fixed-fps 30 res://scenes/cutscene.tscn -- --cutscene=level_1`
ถ้าจะใช้วิดีโอ AI แทน: แปลงเป็น .ogv แล้ววางที่ `assets/videos/<id>.ogv` เกมจะเล่นไฟล์นั้นแทนอัตโนมัติ

## ทดสอบอัตโนมัติ
เปิด `tools/smoke_test.tscn` แล้วกด F6 (หรือ `godot --headless --path . res://tools/smoke_test.tscn`) ผลอยู่ใน Output
